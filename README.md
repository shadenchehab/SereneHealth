# Serene Health playground

PoC site from the Dario `playground-template-main` template. Scope, Success Criteria, and Timeline stay as template copy until the meeting transcript is applied.

## Tabs

- Scope
- Computer — Executive Users Enterprise search and Team Assist
- CX Agent — TrueCare Help / Support screen (PLuG on Chat)
- Support — TrueCare Support · Alliance Support
- Success Criteria
- Timeline

## Login roles

Credentials are stored as four roles:

- Patient
- TrueCare Support
- Alliance Support
- Executive

## Local

```bash
./serve-local.sh
```
